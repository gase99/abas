# ربات تلگرام اخبار و آب‌وهوای خوزستان

این پروژه یک ربات پایتون برای جمع‌آوری خبرهای RSS، فیلتر خبرهای مرتبط با ایران و خوزستان، دریافت پیش‌بینی روزانهٔ شهرهای خوزستان و انتشار پیام‌ها در یک کانال تلگرام است. اجرای زمان‌بندی‌شده با GitHub Actions انجام می‌شود؛ برای اجرای محلی هم می‌توان از فایل `.env` استفاده کرد.

## قابلیت‌ها

- دریافت خبر از BBC فارسی، ایران اینترنشنال و چند فید خبری فارسی دیگر.
- نگه‌داشتن خبرهایی که به ایران یا یکی از شهرها و مناطق خوزستان اشاره می‌کنند.
- رد خبرهایی که یکی از واژه‌های مسدودشده را دارند.
- دریافت خبرهای هواشناسی مرتبط با خوزستان از فیدهای خبری منتخب.
- دریافت پیش‌بینی روزانه از Open-Meteo برای ۳۳ شهر و منطقهٔ تعریف‌شده در تنظیمات.
- جلوگیری از انتشار دوبارهٔ خبرها با نگهداری نشانی و عنوان آن‌ها در `posted.json`.
- محدودیت انتشار در هر اجرا: حداکثر ۵ خبر عمومی و حداکثر ۳ پیام هواشناسی (شامل پیام پیش‌بینی روزانه).
- اجرای زمان‌بندی‌شده در GitHub Actions هر ۳۰ دقیقه؛ پیش‌بینی روزانه حداکثر یک بار در روز تهران منتشر می‌شود.

## پیش‌نیازها

- Python 3.11
- حساب GitHub و Git
- حساب Telegram، یک ربات ساخته‌شده با BotFather و یک کانال که ربات در آن مجوز انتشار پیام داشته باشد

RSS و پیش‌بینی هواشناسی از سرویس‌های عمومی دریافت می‌شوند و این پروژه کلید API آب‌وهوا یا VPS نمی‌خواهد. هزینه و سهمیهٔ GitHub Actions به نوع حساب، عمومی یا خصوصی بودن مخزن و تنظیمات GitHub بستگی دارد؛ پیش از فعال‌کردن اجرای زمان‌بندی‌شده، سهمیه و سیاست‌های حساب خود را بررسی کنید.

## راه‌اندازی تلگرام

1. در تلگرام به `@BotFather` پیام دهید و دستور `/newbot` را اجرا کنید.
2. توکن ربات را در جای امن نگه دارید؛ آن را در کد، مخزن یا پیام عمومی قرار ندهید.
3. یک کانال بسازید و ربات را به‌عنوان مدیر اضافه کنید.
4. مجوز ارسال پیام را برای ربات فعال کنید.
5. شناسهٔ عددی کانال را به دست آورید. برای کانال خصوصی معمولاً شناسه با `-100` شروع می‌شود.

## راه‌اندازی GitHub Actions

1. پروژه را در مخزن GitHub قرار دهید.
2. در مخزن به `Settings` ← `Secrets and variables` ← `Actions` بروید و این دو Secret را بسازید:

   | نام Secret | مقدار |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | توکن BotFather |
   | `TELEGRAM_CHANNEL_ID` | شناسهٔ عددی کانال |

3. در بخش `Actions`، در صورت نیاز اجرای workflowها را فعال کنید.
4. workflow با نام **News and weather bot** را با `Run workflow` اجرا کنید. این کار پیام‌های واقعی را به کانال می‌فرستد.
5. workflow زمان‌بندی‌شده هر ۳۰ دقیقه اجرا می‌شود. طبق تنظیم GitHub، اجرای `schedule` روی شاخهٔ پیش‌فرض مخزن انجام می‌شود.

Workflow تست‌ها را اجرا می‌کند، سپس ربات را اجرا می‌کند و در صورت تغییر، `posted.json` را با مجوز `GITHUB_TOKEN` به همان شاخه push می‌کند. اگر سیاست‌های مخزن push توسط workflow را محدود کرده باشند، باید اجازهٔ نوشتن محتوا برای Actions را در تنظیمات مخزن بررسی کنید.

## اجرای محلی

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

مقادیر واقعی را فقط در `.env` محلی وارد کنید. این فایل در `.gitignore` قرار دارد و نباید commit شود. سپس اجرا کنید:

```bash
python -m src.main
```

اجرای تست‌ها:

```bash
pytest -q
```

## فیدهای خبری و فیلترها

منابع اصلی خبرها و فیدهای هواشناسی در `src/config.py` تعریف شده‌اند. نشانی فیدها ممکن است توسط ارائه‌دهنده تغییر کند یا موقتاً در دسترس نباشد؛ خطای یک فید ثبت می‌شود و بقیهٔ فیدها ادامه می‌یابند.

خبر عمومی پذیرفته می‌شود اگر عنوان یا خلاصه‌اش به ایران یا خوزستان اشاره کند و واژهٔ مسدودشده نداشته باشد. خبر هواشناسی علاوه بر مرتبط‌بودن با وضعیت هوا، باید به خوزستان یا یکی از شهرهای آن اشاره کند. این فیلترها واژه‌محور هستند و تضمین تشخیص کامل معنای خبر را نمی‌دهند؛ فهرست واژه‌ها در `src/config.py` قابل ویرایش است.

مختصات شهرها در `CITY_COORDINATES` قرار دارد. برای افزودن یک شهر، نام فارسی و جفت `(latitude, longitude)` را به آن دیکشنری اضافه کنید. نام شهر همان‌طور که در دیکشنری آمده در پیام پیش‌بینی نمایش داده می‌شود.

Open-Meteo بدون کلید API فراخوانی می‌شود. درخواست‌ها به دسته‌های چندشهری تقسیم شده‌اند؛ اگر یک درخواست ناموفق باشد، خطا ثبت می‌شود و پردازش دسته‌های بعدی ادامه می‌یابد.

## امنیت و عیب‌یابی

- توکن واقعی را در `.env.example`، کد، لاگ یا مخزن قرار ندهید؛ از GitHub Secrets استفاده کنید.
- **Missing required environment variables**: هر دو متغیر `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHANNEL_ID` را تنظیم کنید.
- **401 Unauthorized**: توکن ربات را در BotFather بررسی کنید.
- **403 Forbidden** یا خطای مجوز: بررسی کنید ربات مدیر کانال باشد و اجازهٔ ارسال پیام داشته باشد.
- **chat not found**: شناسهٔ کانال را دوباره بررسی کنید و مطمئن شوید ربات به کانال دسترسی دارد.
- **Open-Meteo request failed**: اتصال یا پاسخ API را بررسی و اجرای بعدی را مشاهده کنید؛ در صورت شکست دسته‌ای، پیش‌بینی همان دسته منتشر نمی‌شود.
- فید RSS خالی یا نامعتبر: نشانی منبع را در `src/config.py` بررسی کنید. خطای یک منبع به‌تنهایی نباید کل چرخه را متوقف کند.
- اگر `posted.json` به‌روزرسانی نمی‌شود، لاگ workflow و مجوز نوشتن `GITHUB_TOKEN` را بررسی کنید.
